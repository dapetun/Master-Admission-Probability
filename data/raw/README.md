# Сырые данные (`data/raw/`)

Сюда кладут **локальные** выгрузки. Файлы `*.xlsx` / `*.xls` / `*.csv` и всё содержимое каталога (кроме этого README и `.gitkeep`) в git не попадают.

## Типы файлов

1. **`*_Budget.xlsx`** — выгрузки MAGREPORTS («Бюджетные места»). В заголовке — программа и кампус; в таблице — код поступающего, приоритет, баллы, согласие, статус и связанные поля.
2. **CSV** — старый/альтернативный формат списков (колонки с кодом поступающего, программой, приоритетом, баллами, согласием, статусом).
3. **Сводка мест (`.xls`)** — опционально, для сборки `seats.yaml` скриптом `scripts/build_seats_yaml.py` (путь к сводке задаётся аргументом).

## Сборка мест

```bash
set PYTHONPATH=.
python scripts/build_seats_yaml.py --summary path\to\сводка.xls
```

Программы без известных КЦП получают `seats: null` и в модели поглощают абитуриентов как EXTERNAL (не «перекидывают» на другие кампусы).

Не коммитьте реальные выгрузки и сводки в публичный репозиторий.
