# Данные

Каталог для **локальных** входных файлов приёмной кампании. Содержимое сырых выгрузок в git **не коммитится**.

| Путь | Назначение |
|---|---|
| `raw/` | Конкурсные списки и опциональные сводки мест |
| `../seats.yaml` | Локальный файл с числом бюджетных мест (не в git; образец — `seats.example.yaml`) |

Поддерживаемые **типы** файлов в `raw/` — см. [raw/README.md](raw/README.md).

Не храните и не публикуйте здесь персональные отчёты, полные дампы кампании и файлы с реальными кодами поступающих.
