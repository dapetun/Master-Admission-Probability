# Master-Admission-Probability

Локальный инструмент на Python для оценки шансов поступления в магистратуру по **приоритетам зачисления** и **согласию на зачисление** (приёмная кампания через суперсервис «Поступление в вуз онлайн» / Госуслуги).

> **Не официальный расчёт.** Результат — модель на основе публичных конкурсных списков и ваших допущений. Решение о зачислении принимает вуз.

## Что делает проект

1. Загружает сразу несколько CSV конкурсных списков (выгрузка вручную).
2. Склеивает абитуриентов по **уникальному коду поступающего**.
3. Симулирует зачисление по **высшему проходному приоритету (ВПП)** при текущих согласиях.
4. Считает сценарии «если подать согласие» для вас и для других.
5. Даёт **оценку вероятности** (Monte Carlo) с оговорками о полноте данных.

Статус: **каркас репозитория**. Алгоритм симуляции будет добавлен отдельно.

## Данные

- Источник v1: **ручная выгрузка** CSV конкурсных списков (Госуслуги / кабинет поступающего).
- Автопарсинг сайта вуза и Госуслуг **не входит** в текущую версию.
- Файлы `*.csv` и локальный `seats.yaml` игнорируются git — не публикуйте чужие списки и не деанонимизируйте коды.

Имя файла обычно такое:

```text
Название_программы.2026-08-16_20-17-34.csv
```

Ключ в `seats.yaml` = часть имени **до** `.2026-...`.

## Юридические и этические рамки

- Конкурсные списки публикуются в обезличенном виде (код поступающего, без ФИО) — это норма Порядка приёма.
- Инструмент рассчитан на **личное локальное** использование открытых сведений.
- Не обходите авторизацию, не снимайте данные массово с ЕПГУ, не сопоставляйте коды с приказами (ФИО).
- Не выкладывайте полные выгрузки списков в публичный репозиторий или сторонний сервис без отдельной правовой оценки.

Подробности модели (ОВП / ВПП, «дыры» в приоритетах вне загруженных программ) будут в документации к симулятору.
